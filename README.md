# Rails and Roadmaps

A daily two-host audio digest of what moved in product management and in
payments/fintech over the last 24 hours.

**Feed:** `https://adil1248.github.io/pm-payments-daily/feed.xml`

Paste that URL into any podcast app that supports adding a feed by URL
(Overcast, Pocket Casts, Apple Podcasts, AntennaPod).

Episodes are generated automatically each weekday morning from public
industry sources.
